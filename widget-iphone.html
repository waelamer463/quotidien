Le widget iPhone

La mascotte, le bloc en cours, ta prochaine tâche, la prochaine prière et le chrono, directement sur ton écran d'accueil.

  1. Installe l'app gratuite Scriptable depuis l'App Store.
  2. Ouvre Scriptable, touche + en haut à droite, puis colle le script (appui long → Coller).
  3. Touche le titre « Untitled Script » en haut et renomme-le Quotidien, puis Done.
  4. Touche le script pour le lancer : tape ton e-mail, ouvre le lien reçu, touche « Copier le code », reviens dans Scriptable et colle-le.
  5. Sur l'écran d'accueil : appui long sur un espace vide → Modifier → Ajouter un widget → Scriptable → choisis la taille moyenne (ou petite) → Ajouter le widget.
  6. Appui long sur le widget → Modifier le widget → Script : choisis Quotidien.

Le widget se met à jour environ toutes les 15 minutes (c'est iOS qui décide). Le chrono, lui, défile en direct.
